# Calculator Project

This is a simple calculator project that allows you to perform basic arithmetic operations.

## How to Run

To run the calculator, execute the `main.py` file:

```bash
python main.py
```

## Example Usage

The calculator will prompt you to enter numbers and an operation. For example:

```
Enter the first number: 10
Enter the operation (+, -, *, /): +
Enter the second number: 5
Result: 15.0
```
